# TWEtaChecker

**테일즈위버 1:1 대화 상대의 에타 레벨을 알려 주는 프로그램** — TWChatOverlay의 "1:1 대화 에타 확인" 기능만 따로 떼어 낸 것입니다.

게임 메모리를 읽거나 변조하지 않고, 게임이 직접 남기는 메신저 로그 파일(`MsgerLog\*.html`)만 읽습니다.

## 하는 일

1:1 대화 창이 열리면 상대 아이디를 읽어 [TW DB 에타 순위](https://talesdb.xyz/#/extra) 데이터에서 레벨을 찾아 작은 팝업으로 보여 줍니다.

* **에타 레벨** — 상대마다 `Lv 84` 알약. 색은 레벨 구간(1~20 / 21~40 / 41~60 / 61~80 / 81~)에 따라 다릅니다. 랭킹에 없으면 `정보 없음`.
* **사칭 주의 표시** (빨간 글씨) — 에타 랭킹에 **없는** 아이디에만 붙습니다. 랭킹에 있으면 실제 캐릭터가 확인된 것이라 표시하지 않습니다.
  * 아이디에 한글·영문·숫자가 아닌 글자(`_` `.` 전각 `Ａ` 등)가 있으면 그 글자를 빨갛게 — `주의 - 특수 문자 포함`
  * `길드` `클랜` `유저` `운영자` `1-` `2-` `3-` `M-` `S-` 같은 문구가 들어 있으면 — `주의 - 의심 문구 포함`
  * 랭킹에 닮은 아이디가 있으면 — `주의 - 닮은꼴 아이디 YulLin (Lv 84)`
    * 닮은꼴: `l`/`I`/`1`, `O`/`0`, 전각·원문자·로마숫자, 그리스·키릴 닮은 글자, 한글 된소리(`드드해` ↔ `뜨뜨해`)만 다른 아이디
    * 비슷한: 글자 하나가 더 붙거나 빠지거나 바뀐 아이디 (`드드해` ↔ `드드해1`)

## 시작하기

1. 테일즈위버에서 메신저 로그가 켜져 있어야 합니다 (설치 폴더의 `MsgerLog`에 HTML 파일이 생기면 됩니다).
2. `TWEtaChecker.exe`를 실행합니다. **처음 실행하면 테일즈위버 설치 폴더(보통 `C:\Nexon\TalesWeaver`)를 고르는 창이 뜹니다.** 메신저 로그는 그 아래 `MsgerLog`로 자동 연결됩니다. 아직 `MsgerLog`가 없으면 게임이 만들 때까지 기다렸다가 감시를 시작합니다.
3. 상태 창이 뜹니다 — 테일즈위버 폴더, 1:1 대화 감시 상태, 에타 랭킹 기준일을 보여 줍니다.
   * **테스트 팝업** — 모양 확인용 가짜 팝업
   * **설정**
     * 글자 크기 `−` / `+`
     * 팝업 위치 — [위치 조정]을 누르면 끌 수 있는 미리보기 팝업이 뜹니다. 원하는 자리로 옮기고 [위치 저장]을 누르면 저장됩니다.
     * 테일즈위버 폴더 [변경…]
     * 에타 랭킹 [새로 고침] — 평소엔 매일 10시 이후 자동으로 한 번 받습니다
     * 설정 폴더 열기 — `Config\settings.json` (테일즈위버 폴더·글자 크기·팝업 위치만 저장), `Config\app.log`
4. **최소화하면 트레이로 들어갑니다.** 트레이 아이콘을 두 번 누르면 다시 열립니다. 트레이 우클릭 메뉴에는 **종료**만 있습니다. 창의 닫기(X)도 프로그램을 끕니다.

`TWEtaChecker.exe --demo`로 실행하면 시작하자마자 테스트 팝업이 뜹니다.

## 빌드

.NET 8 SDK가 필요합니다.

```
dotnet build -c Release
```
